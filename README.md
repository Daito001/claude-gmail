# Claude Gmail

Persönliches Werkzeug von Florian Kern. Es verbindet seine eigenen Gmail-Postfächer über einen lokal laufenden MCP-Server ([workspace-mcp](https://github.com/taylorwilsdon/google_workspace_mcp)) mit KI-Assistenten auf seinem Mac.

Die App ist nicht für andere Nutzer gedacht und wird nicht angeboten. Sie liest Mails (`gmail.readonly`) und legt Entwürfe an (`gmail.compose`). Senden ist in der lokalen Software abgeschaltet, Löschen und Ändern sind nicht freigegeben.
